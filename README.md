# CareWell Clinic – Sample Website

A modern, responsive clinic website (sample project).

**Live demo:** https://hanif-ryk.github.io/Clinic/

## Features
- Marketplace-style design: big search bar, service circles and doctor cards
- Search doctors by name, specialty or service; filter by "Available today", "Saved" and "Top rated"
- Save favourite doctors with the heart button (remembered on the device)
- Health check packages, patient reviews and FAQ
- Booking form that sends the appointment to the clinic's WhatsApp; "Book" on a doctor or package pre-selects it
- Floating WhatsApp chat button and a WhatsApp health-tips button
- Basic SEO (title, description, social preview tags)
- Fast: a single HTML file, no frameworks

## Customize
Open `index.html` and change the clinic name, phone, address and texts. Edit the `DOCTORS` list near the bottom to add your own doctors, fees and ratings.
Set the clinic's WhatsApp number in the `WHATSAPP` line near the bottom of the file.
